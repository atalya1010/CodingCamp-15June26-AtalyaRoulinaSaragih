# 🚀 AI To-Do Dashboard

A modern productivity dashboard with AI Insight to help users manage tasks efficiently and improve daily performance.

![Dashboard](assets/dashboard.png)

---

## 🎯 Features

* ✅ To-Do List Management
* 📊 Task Progress Tracking
* 🤖 AI Insight (Dynamic Productivity Message)
* ⏱ Pomodoro Timer
* 📈 Chart Visualization (Chart.js)

---

## 🧠 AI Insight Logic

* 🔥 If task completion > 80%
  → **"Excellent productivity 🔥"**

* ⚠️ If task completion < 50%
  → **"You need improvement ⚠️"**

* 📌 Dynamic message based on user activity
